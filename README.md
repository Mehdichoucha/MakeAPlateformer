- Titre du jeu:
  Time Ganging Up (Le Temps se Ligue Contre Nous)

- Courte description de notre projet:

Il s'agit d'un Prototype de jeu de plateforme 2D réalisé sous Unity 6.6 (60006.10f1) en langage C# 0 partir du GDD Time Ganging Up. Des individus captifs du passé (Cowboy, Ninja, Pugiliste, Chevalier) sont retenues prisonniers par une organisation venue du futur et doivent s'échapper. Le joueur a la possibilité d'alterner entre les quatre personnages différents, chacun ayant des capacités spécifiques, pour traverser le niveau, détruire des obstacles et vaincre les robots ennemis.
