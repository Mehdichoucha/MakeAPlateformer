## Titre du jeu:
  Time Ganging Up (Le Temps se Ligue Contre Nous)

## Courte description de notre projet:

Il s'agit d'un Prototype de jeu de plateforme 2D réalisé sous Unity 6.3 en langage C# à partir du GDD Time Ganging Up. Des individus d'une époque du passé (Cowboy, Ninja, Pugiliste, Chevalier) sont retenues prisonniers par une organisation de super méchants venue du futur pour les étudier et doivent s'échapper. Le joueur a la possibilité d'alterner entre les quatre personnages différents, chacun ayant des capacités spécifiques, pour traverser le niveau, détruire des obstacles et vaincre les robots ennemis.

## Mode d'emploi pour démarrer le projet:

  - 1 - Installer Unity Hub et Unity 6.3
  - 2 - Cloner le dépôt : git clone https://github.com/Mehdichoucha/MakeAPlateformer.git
  - 3 - Ouvrir le dossier du projet dans Unity Hub
  - 4 - Ouvrir la scène Assets/Scenes/[NomScene].unity et appuyer sur Play

## Contrôles
### Commandes générales :
Touche|Action
-|-
Q, A / D|Aller à gauche / Aller à droite
Espace|Sauter
S|S'accroupir
Z / W|Interagir / entrer dans un passage
1 / 2 / 3 / 4|Changement de personnage : Cowboy / Ninja / Pugiliste / Chevalier
Clic gauche|Attaque principale
Clic droit|Action spéciale (viser / s'accrocher / esquiver / parer)
Souris|Direction de l'action à Précision du Personnage
### Commandes du Cowboy :
Touche|Action
-|-
Clic Gauche|Tirer
Maintenir Bouton Souris Droit|Viser
Mouvements Souris|Direction du Tir
### Commandes du Ninja :
Touche|Action
-|-
Bouton Souris Gauche|Attaque
S + Bouton Souris Gauche|Attaque Furtive
Bouton Souris Droit|S’accrocher aux Rebords/Parois
Mouvements Souris|Direction de l’Attaque
### Commandes du Pugiliste :
Touche|Action
-|-
Bouton Souris Gauche|Attaquer
Maintenir Bouton Souris Gauche|Attaque Puissante
Bouton Souris Droit|Esquive / Pas en Arrière
Bouton Souris Droit -> Bouton Souris Gauche|Contre-Attaque
Bouton Souris Droit -> Maintenir Bouton Souris Gauche|Contre-Attaque Puissante
Mouvements Souris|Direction de l’Attaque
### Commandes du Chevalier :
Touche|Action
-|-
Bouton Souris Gauche|Attaquer
Maintenir Bouton Souris Droit|Parer au Bouclier
Mouvements Souris|Direction du Bouclier
