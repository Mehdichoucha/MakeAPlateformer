- Titre du jeu:
  Time Ganging Up (Le Temps se Ligue Contre Nous)

- Courte description de notre projet:

Il s'agit d'un Prototype de jeu de plateforme 2D réalisé sous Unity 6.6 (60006.10f1) en langage C# à partir du GDD Time Ganging Up. Des individus captifs du passé (Cowboy, Ninja, Pugiliste, Chevalier) sont retenues prisonniers par une organisation venue du futur et doivent s'échapper. Le joueur a la possibilité d'alterner entre les quatre personnages différents, chacun ayant des capacités spécifiques, pour traverser le niveau, détruire des obstacles et vaincre les robots ennemis.

- Mode d'emploi pour démarrer le projet:

  - 1 - Installer Unity Hub et Unity 6.6 (60006.10f1)
  - 2 - Cloner le dépôt : git clone https://github.com/Mehdichoucha/MakeAPlateformer.git
  - 3 - Ouvrir le dossier du projet dans Unity Hub
  - 4 - Ouvrir la scène Assets/Scenes/[NomScene].unity et appuyer sur Play

Contrôles

Touche	  Action

Q / A, D	Aller à gauche, à droite
Espace	Sauter
S	S'accroupir
Z / W	Interagir / entrer dans un passage
1 / 2 / 3 / 4	Cowboy / Ninja / Pugiliste / Chevalier
Clic gauche	Attaque principale
Clic droit	Action spéciale (viser / s'accrocher / esquiver / parer)
Souris	Direction de l'action
R	Recharger (Cowboy)
